🏢 Rotas do Prédio com Grafos
Trabalho prático da unidade curricular de Algoritmos e Estruturas de Dados II do Senac Campus Pelotas, lecionada pelo professor Pablo De Chiaro. A missão aqui foi mapear o prédio inteiro a partir do LabTec, transformar o mapa num grafo ponderado e botar tudo para rodar numa API rápida e funcional.
